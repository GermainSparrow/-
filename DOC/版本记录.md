# 版本记录

## 版本规则

项目版本号采用 `主版本号.次版本号.修订号` 格式：

- 主版本号：出现不兼容的架构调整或数据格式调整时递增。
- 次版本号：新增功能模块或重要业务能力时递增。
- 修订号：缺陷修复、文案调整、样式优化、文档补充时递增。

## v0.2.0

发布日期：2026-07-07

当前状态：实现第一版本地脱敏与实体级还原闭环。

### 已完成

- 新增不可恢复脱敏流程，导出脱敏文件和脱敏报告。
- 新增可恢复实体脱敏流程，导出脱敏文件、加密映射文件和脱敏报告。
- 新增口令或密钥文件两种映射解锁方式。
- 新增 `AES-256-GCM` 加密映射文件，随机生成每文档 `DEK`，口令模式使用 `scrypt` 派生包装密钥。
- 新增规则识别手机号、身份证、邮箱、账号类数字串。
- 新增人工确认和补充实体能力。
- 新增 TXT、MD、DOCX、XLSX、文本型 PDF 的脱敏处理。
- 新增实体级还原处理，保留稳定标签时可还原，实体被删除时不补回。
- 新增主进程服务层和最小 IPC API。
- 新增 Node 内置测试，覆盖实体识别、替换顺序、加密解密、错误口令、密钥文件、TXT、DOCX、XLSX、PDF 基础脱敏。
- 新增依赖审计 override，修复 ExcelJS 间接依赖 `uuid` 的中风险审计项。

### 已知限制

- 不支持旧版 `doc`、`xls`，需转换为 `docx`、`xlsx`。
- 不做 OCR，扫描 PDF 或含图片内容的 PDF 会阻断。
- PDF 输出为重生成的安全文本 PDF，不保持原 PDF 版式。
- DOCX/XLSX 中图片、嵌入对象、宏、修订记录、隐藏文本等无法确认内容会阻断。
- 当前实体识别以规则为主，公司、人名、地址等建议人工补充确认。
- 暂未实现任务记录、规则配置持久化、批处理队列和安装包打包。

## v0.1.0

发布日期：2026-07-07

当前状态：Electron 初始版，可本地启动并展示基础工作台。

### 已完成

- 初始化 Electron 桌面应用工程。
- 配置主进程入口 `src/main/main.js`。
- 配置安全的 preload 桥接 `src/main/preload.js`。
- 配置渲染层页面 `src/renderer/index.html`、样式 `src/renderer/styles.css` 和交互脚本 `src/renderer/renderer.js`。
- 支持通过系统文件选择窗口选择待处理文档。
- 支持展示已选择文件的名称、路径、扩展名和待处理状态。
- 支持脱敏处理、还原处理两个模式按钮的前端选中态切换。
- 支持在界面显示应用版本号。

### 已知限制

- 暂未实现真实的文档内容读取、解析、脱敏和还原逻辑。
- 暂未实现规则配置、任务记录、批处理队列和结果导出。
- 暂未引入自动化测试、打包发布配置和日志系统。
- 当前文件类型过滤仅作为入口筛选，不代表对应格式已经具备处理能力。

### 下一步建议

- 明确脱敏规则模型和映射表格式。
- 增加文档解析层，分别处理 `doc`、`docx`、`pdf`、`txt`、`md`、`xlsx` 等格式。
- 增加任务状态流转，包括待处理、处理中、成功、失败。
- 增加本地输出目录选择和处理结果导出。
- 增加错误提示、操作日志和基础测试。
